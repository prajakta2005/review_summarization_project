## Key findings

- Credibility-aware summarization cut fake-sentence contamination from 92% to 42% and raised ROUGE-L against a genuine-only reference from 0.314 to 0.405 (5-sentence summaries, averaged over categories).
- The best classifier is SVM (linear) · hybrid (F1 0.954); the deployed, explainable Random Forest on 6 features reaches F1 0.771. DistilBERT results are still pending (Colab).
- Ablation: removing repetition_ratio costs the most F1 (-0.192).
- SHAP explanations are faithful to the model (resetting the top feature moves the prediction by 0.101 vs 0.032 for a random feature); the original z-score explanations pick the same top feature only 32% of the time.
- All results use the full dataset: 40,412 reviews across 10 categories.
